# SMW Stream Tracker Desktop v1.0.9

Version 1.0.9 is the complete setup, localization, catalog, FXPAK Pro, OBS,
LiveSplit, and statistics refinement release.

## Changes

- Adds a translated guided first-run workflow that flashes every required
  connection, catalog, refresh, download, patch, FXPAK, and OBS step in order.
- Adds consistent blue app-style message popups throughout the application.
- Uses emoji-safe filenames for FXPAK Pro USB and mounted-SD transfers while
  preserving each original catalog title in My Tracker and the current-game
  display.
- Adds automatic download and configuration buttons for separate Game and Level
  LiveSplit copies on ports 16834 and 16835, including TCP server auto-start.
- Expands OBS text-file instructions, including how to replace an existing OBS
  or Streamlabs text source path so it updates automatically.
- Fixes the packaged OBS Text File Setup dialog so its translated paths, reuse
  note, Copy controls, and setup instructions open reliably.
- Improves the SMW Central catalog and download pages with blue drop-down arrows,
  yellow scrollbars, better column spacing, and light-blue cell borders.
- Applies light-blue horizontal and vertical cell borders to every data table.
- Revises the statistics Overview layout, enlarges the two charts, and removes
  unused space below Progress by Difficulty.
- Completes the interface and setup-guide catalogs across English, Australian
  English, Spanish, French, German, and Brazilian Portuguese. Australian English
  includes playful local wording throughout.
- Adds a translated Join Discord button to About & Updates for help and contact.
- Refreshes the repository screenshots for the v1.0.9 feature set.

## Downloads

- `SMWStreamTracker_Setup_1.0.9.exe` - complete installer and repair package.
- `SMWStreamTracker_Update_1.0.9.exe` - updater for a working installation.
- `SMWStreamTracker_Desktop_1.0.9_Source.zip` - source, tests, documentation,
  installer definitions, screenshots, and required assets.
- `SHA256SUMS_1.0.9.txt` - SHA-256 checksums for every release download.

These files are intentionally unsigned, so Windows can display an Unknown
publisher or Microsoft Defender SmartScreen warning. Compare downloaded files
with the published SHA-256 checksums before running them.

SMW Stream Tracker never includes or downloads a commercial Super Mario World
base ROM. Users must provide their own legally obtained clean ROM when applying
moderated patches.
