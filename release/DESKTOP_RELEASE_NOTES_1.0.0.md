# SMW Stream Tracker Desktop v1.0.0

This is the initial release from the new SMW Stream Tracker repository.

## Highlights

- Always-on tracking for FXPAK Pro and RetroArch.
- Searchable SMW Central moderated-hack catalog, missing-hack downloader, and
  complete catalog viewer.
- Personal tracker with editable progress, ratings, playtime, colors, gradients,
  statistics, exports, and automatic backups.
- Stream-friendly current-hack and timer output for OBS.
- Optional SNI, QUsb2Snes, RetroArch, and the SNI-compatible bsnes-mercury
  Performance core in the setup wizard.
- Multilingual installer and documentation, including Australian.
- First-run health checks, redacted diagnostics, rollback-capable updates, and
  recovery backups.
- Correct RetroArch UDP Network Commands detection and actionable SNI/QUsb2Snes
  connection guidance.

## Downloads

- `SMWStreamTracker_Setup_1.0.0.exe` — complete first-time installer.
- `SMWStreamTracker_Update_1.0.0.exe` — updater for an existing installation.
- `SMWStreamTracker_Desktop_1.0.0_Source.zip` — source, installer definitions,
  documentation, and required assets.

The application never includes or downloads a commercial Super Mario World
base ROM. Users must supply their own legally obtained clean ROM for patching.
