PRIVACIDAD DE SMW STREAM TRACKER
================================

SMW Stream Tracker no recopila telemetría ni sube ROM a servicios de Internet.
Puede transferir una ROM parcheada al MiSTer del usuario por la red local al
iniciarla.

La aplicación solo usa la red para las funciones que el usuario solicita o
activa: el catálogo y los parches moderados de SMW Central, las comprobaciones
de versiones de GitHub, la sincronización opcional con Google Sheets, las
descargas opcionales de SNI, QUsb2Snes, RetroArch y núcleos de Libretro, la
comunicación local con esas herramientas o MiSTer, la descarga verificada de
snid y la configuración SSH/SFTP de MiSTer, y el formulario opcional de
Microsoft Forms.

Music Identifier graba temporalmente la fuente seleccionada en un archivo
local y lo elimina después de la comparación. El audio original nunca sale del
equipo. La aplicación solo envía al servicio compartido de reconocimiento una
secuencia corta de valores de huella acústica de 32 bits no reconstruibles. El
servicio devuelve los metadatos coincidentes del catálogo de SMW Central. No se
incluyen datos de ROM, nombres de usuario, datos de Twitch ni rutas de archivos.
El catálogo musical completo no se descarga ni se almacena sin conexión. Los
Resultados de canciones de la comunidad opcionales solo suben una huella después
de que el usuario confirme el resultado correcto.

Comentarios y sugerencias abre un formulario público de Microsoft Forms dentro
de una ventana web integrada de SMW Stream Tracker. Si la vista web integrada
no está disponible, se abre el mismo formulario en el navegador predeterminado. El formulario no
solicita el nombre ni el correo electrónico. La aplicación no adjunta ajustes,
diagnósticos, rutas de archivos, información de ROM ni datos del tracker. Solo
se envían las respuestas que el usuario escribe.

Microsoft puede procesar datos normales del servicio según su política de
privacidad cuando se abre o envía el formulario. SMW Stream Tracker no recibe
ni almacena esos datos del servicio.

La contraseña SSH de MiSTer solo se conserva en memoria durante la sesión y
nunca se guarda. Una clave de host guardada permite reconocer ese MiSTer.

Los datos del tracker, ajustes, temporizadores, asignaciones, copias de
recuperación y registros de errores se guardan localmente. Copiar diagnósticos
oculta nombres de usuario, nombres de ROM y rutas personales.

SMW Stream Tracker nunca incluye, descarga ni sube una ROM base comercial.
