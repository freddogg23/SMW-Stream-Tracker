Release 1.0.11

* Adds native Windows and macOS behavior with reproducible Apple Silicon and Intel Mac application builds.
* Adds platform-correct Mac downloads and configuration for SNI, QUsb2Snes, RetroArch, and the bsnes-mercury Performance core.
* Provides tracker-controlled Game and Level timer windows plus OBS timer text files on Mac, where classic LiveSplit is unavailable.
* Makes the main window, banner, and My Tracker table substantially smoother while moving, resizing, and scrolling.
* Adds vertical main-dashboard scrolling for shorter windows and prevents table borders from becoming misaligned while scrolling.
* Improves text rendering and reduces startup color flashing by applying saved table styling before the tracker becomes visible.
* Adds a translated blue Add to Tracker form with complete hack, progress, rating, playtime, date, death, and notes fields.
* Fixes custom unmoderated hacks so they remain beside the full catalog and can be patched and uploaded from Download & Patch Missing Hacks.
* Makes the main Refresh button request a safe FXPAK Pro game reset before reconnecting to a running Super Nt session.
* Converts Remove from My Tracker to the translated blue confirmation dialog while keeping the full data-removal warning.
* Preserves the v1.0.10 emoji-safe FXPAK mappings, guided setup, catalog, OBS, installer, localization, and update behavior.
* Uses the existing repository screenshots; no new screenshots are included in v1.0.11.
