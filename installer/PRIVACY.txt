SMW STREAM TRACKER PRIVACY
==========================

SMW Stream Tracker does not collect telemetry and does not upload ROM files to
an internet service. It can transfer a selected patched ROM to the user's own
MiSTer over the local network when the user launches it.

The app uses the network only for features the user requests or enables:

* SMW Central catalog and moderated patch information.
* GitHub release checks and checksum-verified updater downloads.
* Optional Google Sheets synchronization through the URL the user supplies.
* Optional installer downloads for SNI, QUsb2Snes, RetroArch, and Libretro cores.
* Local communication with SNI, QUsb2Snes, FXPAK Pro, RetroArch, or MiSTer.
* Optional checksum-verified snid download and SSH/SFTP setup on the user's MiSTer.
* The optional Microsoft Forms feedback page that the user chooses to open.

Feedback & Suggestions opens a public Microsoft Forms page inside a dedicated
SMW Stream Tracker web-view window. If the embedded web view is unavailable,
the same form is opened in the user's default browser. The form does not ask for the respondent's
name or email address. The app does not attach settings, diagnostics, ROM
information, file paths, or tracker data. Only answers the user enters into the
form are submitted.

Microsoft may process normal service data under its privacy policy when the form
is opened or submitted. SMW Stream Tracker does not receive or store that service
data.

The MiSTer SSH password is kept only in memory for the current app session and
is never saved. A saved host key is used to recognize that MiSTer later.

Tracker data, settings, timer state, mappings, recovery backups, and error logs
are stored locally. Error logs may contain technical file paths, but the Copy
Diagnostics feature redacts usernames, ROM names, and personal paths before
placing a report on the clipboard.

SMW Stream Tracker never includes, downloads, or uploads a commercial base ROM.
