# SMW Stream Tracker Desktop v2.0.1

Version 2.0.1 adds live RetroAchievements displays and completes the latest
Stream Desk setup, OBS, Overview, library, MiSTer, and installer refinements.

## Highlights

- Shows real RetroAchievements progress, recent unlocks, and official badge
  artwork on the Overview and each recognized selected game.
- Adds an editable `achievements.txt` source for OBS and Streamlabs, including
  formatting controls and a live preview in OBS Text Settings.
- Repairs incomplete Game Library caches automatically and completes a full
  background scan so every local game is available.
- Updates MiSTer setup, RetroAchievements setup, OBS Text File Setup, and OBS
  Text Settings to the Stream Desk interface with fitted content and clearer,
  larger actions.
- Fits the complete Overview into compact windows without scrolling and stops
  the resize feedback loop that could make the page twitch.
- Improves dashboard game shortcuts, MiSTer death handling and save imports,
  and exact-ROM relaunch reliability.
- Adds one linked thank-you message for Jole_12, PixelPadlock, and the other
  community testers.
- Keeps the installer and updater finish pages clean by removing duplicate or
  clipped native controls while preserving the themed launch options.

## Downloads

- `SMWStreamTracker.exe` - portable single-file Windows application.
- `SMWStreamTracker_Setup_2.0.1.exe` - complete Windows installer.
- `SMWStreamTracker_Update_2.0.1.exe` - checksum-verified in-app updater.
- `SMWStreamTracker_Desktop_2.0.1_Source.zip` - curated release source.
- `SHA256SUMS_2.0.1.txt` - SHA-256 checksums for every generated artifact.

The current Windows application and installers are unsigned. Windows may show
a SmartScreen warning until the project develops reputation with Microsoft.
