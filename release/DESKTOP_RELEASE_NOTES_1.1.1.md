# SMW Stream Tracker Desktop v1.1.1

Version 1.1.1 expands the in-app SMW Central experience, adds a movable radio
player and OBS-friendly popups, and safely extends MiSTer save states.

## Highlights

- Adds an integrated SMW Central home experience with live content cards,
  richer hack details, tag search, screenshots, and account/comment tools.
- Adds SMW Central Radio and SPC playback. The compact radio player can be
  moved, resized, minimized, and kept open while using the tracker.
- Adds optional OBS Capture Mode so blue tracker popups can stay inside the
  main window and appear through one OBS Window Capture source.
- Adds compatibility-checked MiSTer save states 5–11 with an exact restorable
  backup. Native slots 1–4 remain intact and F12 still opens the MiSTer menu.
- Reorganizes Setup, application, OBS, and LiveSplit menus while preserving the
  guided setup flow, and returns to the dashboard after Game Mode launches.
- Fixes stale MiSTer connection data affecting RetroArch, window resizing edge
  cases, and the Google Sheets settings close flow.
- Completes every new interface phrase in English, Australian, Spanish, French,
  German, and Brazilian Portuguese, backed by a deeper automated audit.
