# Game Mode Sprite Animations

## Game Mode Menu Icons

The eight transparent PNG menu icons were created with OpenAI ImageGen for
this project from the tester-supplied visual directions. They cover Hot Potato,
Mario Kaizo Challenge, Play Random Hack, Hack Draft, Difficulty Vine, Creator
Spotlight, Time Capsule, and Hall of Fame Tour. The Mario likeness remains the
property of Nintendo; the other icons are original UI artwork.

These small Super Mario World sprite GIFs are displayed in the Game Modes UI.
They were downloaded from the Super Mario Wiki file pages listed below. The
wiki identifies each one as a fair-use game sprite; the underlying characters
and artwork are owned by Nintendo.

- `coin_spin.gif` — [SMW Sprite Coin Spinning.gif](https://www.mariowiki.com/File:SMW_Sprite_Coin_Spinning.gif)
- `baby_yoshi.gif` — [SMW Baby Yoshi.gif](https://www.mariowiki.com/File:SMW_Baby_Yoshi.gif)
- `climbing_mario.gif` — [Climbfromfront.gif](https://www.mariowiki.com/File:Climbfromfront.gif)
- `invincible_mario.gif` — [SMW Invincible Mario sprite.gif](https://www.mariowiki.com/File:SMW_Invincible_Mario_sprite.gif)
- `cape_spin.gif` — [SMW MarioCapeSpin.gif](https://www.mariowiki.com/File:SMW_MarioCapeSpin.gif)
- `green_yoshi.gif` — [SMW-GreenYoshiMapAnimated.gif](https://www.mariowiki.com/File:SMW-GreenYoshiMapAnimated.gif)
- `yoshi_fireball.gif` — [SMWYoshiFireball.gif](https://www.mariowiki.com/File:SMWYoshiFireball.gif)
