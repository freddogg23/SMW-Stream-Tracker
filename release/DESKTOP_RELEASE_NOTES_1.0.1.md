# SMW Stream Tracker Desktop v1.0.1

This release brings the latest tracker, catalog, downloader, OBS, privacy, and interface improvements together in one tested desktop build.

## What's new

- Click the current hack name to open its SMW Central page.
- See the catalog's last refresh time and the number of newly available hacks in My Tracker.
- Browse and manage an FXPAK Pro SD card with search, letter filters, sortable columns, and direct ROM removal.
- Open SMW Central pages and patch downloads from the catalog and missing-hacks lists.
- Customize OBS author and exit text, and automatically create `author.txt`, `exits.txt`, `hack_name.txt`, `level_timer.txt`, and `game_timer.txt`.
- Receive separate streamer privacy warnings before opening screens that may reveal local file paths.
- Filter tables by letter with article-aware sorting, so titles beginning with “The,” “A,” or “An” are filed under the next word.
- Use centered table content, dropdown values, popup choices, filter boxes, and headers aligned over the usable text area.
- Keep saved downloader folders, mounted-SD copying, FXPAK Pro USB uploads, and appearance choices across updates.
- Download patches even when an unrelated documentation file inside a patch ZIP is damaged.

## Downloads

- `SMWStreamTracker_Setup_1.0.1.exe` — complete first-time installer.
- `SMWStreamTracker_Update_1.0.1.exe` — updater for an existing installation.
- `SMWStreamTracker.exe` — portable desktop application.
- `SMWStreamTracker_Desktop_1.0.1_Source.zip` — source, tests, installer definitions, documentation, and required assets.
- `SHA256SUMS_1.0.1.txt` — checksums for verifying every download.

SMW Stream Tracker never includes or downloads a commercial Super Mario World base ROM. Users must provide their own legally obtained clean ROM when applying moderated patches.
