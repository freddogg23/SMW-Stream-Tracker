Release 2.0.1

* Adds live RetroAchievements progress, recent unlocks, and official badge artwork to the Overview and every recognized selected game.
* Adds an achievements.txt source for OBS and Streamlabs with editable formatting and a live preview in OBS Text Settings.
* Repairs partial Game Library caches with a complete background scan so the full local library reliably appears.
* Gives MiSTer setup, RetroAchievements setup, OBS Text File Setup, and OBS Text Settings the Stream Desk interface with larger actions and properly fitted content.
* Keeps every Overview card visible without scrolling and removes the resize feedback loop that could make the page twitch at compact window sizes.
* Improves dashboard game shortcuts, MiSTer death handling, MiSTer save imports, and exact-ROM relaunch reliability.
* Adds one linked thank-you message for Jole_12, PixelPadlock, and the other community testers.
* Prevents duplicate or clipped native controls on the installer and updater finish pages while preserving the themed launch options.
