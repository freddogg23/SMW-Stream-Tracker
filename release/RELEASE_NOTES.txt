Release 1.0.2

* Adds a publicly trusted Microsoft Artifact Signing signature to the app, complete installer, and updater.
* Shows FredDOGG23 as the verified Windows publisher for authentic release files.
* Uses Microsoft's Artifact Signing timestamp service so signatures remain valid after certificate rotation.
* Establishes a trusted publisher baseline for secure automatic updates after this full installer is installed.
* Existing unsigned installations must run the full 1.0.2 installer once before automatic signed updates can be installed.
