Release 1.0.10

* Replaces every emoji in FXPAK Pro ROM filenames with readable Unicode names while preserving official hack titles inside the tracker.
* Links FXPAK aliases to SMW Central IDs, repairs older local emoji ROMs, and recognizes successful uploads instead of reporting them as missing.
* Prevents the live SNI/QUsb2Snes connection from blocking FXPAK transfers and reconnects it automatically afterward.
* Corrects the guided connection gate and leaves only the remaining required SNI or RetroArch option flashing.
* Adds the blue OBS feature chooser and fixes creation and display of OBS text-output folders.
* Moves translated LiveSplit Timer Setup into Help > Setup beside App Setup and OBS Text Setup.
* Adds Reset Catalog with a recovery backup while preserving tracker progress, custom hacks, ROM mappings, and ROM files.
* Prevents a false new-moderated badge when the live SMW Central catalog is ahead of its GitHub mirror.
* Adds the branded dark-blue installer, portable RetroArch option, reusable folder choices, optional OBS output, and single-copy install handling.
* Preserves RetroArch, SNI, QUsb2Snes, and ROM files during fresh reinstall and complete uninstall workflows.
* Completes translations and the latest popup, table, scrollbar, statistics, downloader, catalog, timer, and setup reliability improvements.
* Uses the existing repository screenshots; no new screenshots are included in v1.0.10.
