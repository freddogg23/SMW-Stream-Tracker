# SMW Stream Tracker Desktop v1.1.2

Version 1.1.2 improves catalog navigation and table customization.

## Improvements

- Adds clickable SMW Central page and patch-download links to every available
  entry in View Complete Catalog.
- Centers headings and cell contents throughout the tracker, complete catalog,
  missing-hacks list, game library, custom hacks, difficulty progress, and
  recent activity.
- Makes each Progress by Difficulty color directly editable from its
  right-click menu and immediately refreshes matching colors throughout the
  app.
- Adds horizontal scrolling to the catalog and downloader tables so every
  column remains accessible in narrower windows.
- Includes the v1.1.1 embedded Feedback & Suggestions window fix.

## Downloads

- `SMWStreamTracker.exe` - portable single-file application.
- `SMWStreamTracker_Setup_1.1.2.exe` - complete unsigned installer.
- `SMWStreamTracker_Update_1.1.2.exe` - checksum-verified in-app updater.
- `SMWStreamTracker_Desktop_1.1.2_Source.zip` - complete release source.
- `SHA256SUMS_1.1.2.txt` - SHA-256 checksums for every release artifact.

The application and installers are intentionally unsigned. Windows may show a
SmartScreen warning until the project develops reputation with Microsoft.
