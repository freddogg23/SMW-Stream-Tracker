Release 1.0.5

* Fixes the Tcl/Tk startup failure that could prevent the app from opening after an update.
* Packages a verified window-system runtime beside the installed application as a stable fallback.
* Tests a real hidden app window before an update is accepted or the updated app is launched.
* Automatically restores the previous working executable when the updated app fails its startup check.
* Stops release packaging when the finished executable cannot pass the same startup check.
* Removes a development-only local path from the packaged Tcl startup files.
