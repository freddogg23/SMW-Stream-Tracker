Release 1.0.4

* Restores the full banner, platform artwork, menu images, and application photos in packaged builds.
* Packages every banner asset directory used by the desktop application.
* Accepts update manifests saved as either ordinary UTF-8 or UTF-8 with a byte-order mark.
* Generates future update manifests as BOM-free UTF-8 for compatibility with every installed version.
* Keeps successfully loaded artwork visible if one optional image cannot be opened and records a diagnostic error instead.
