Release 1.0.2

* Adds separate Level Deaths and Total Deaths counters with OBS files and per-ROM, per-save-slot persistence.
* Adds Level Deaths and Total Deaths to the main override area, using the same Apply Override button.
* Adds a five-item Replay Recent Hack selector that remembers recent games across sessions.
* Adds an editable Total Deaths column to My Tracker and marks older completions with a yellow asterisk when no historical death count exists.
* Prevents opening intro cutscenes from starting the level timer or counting deaths.
* Keeps older-hack level timing through death-to-overworld transitions and resets only after a confirmed clear or different level.
* Improves first-death and missed-death detection while avoiding duplicate counts.
* Expands OBS text settings and multilingual setup documentation for both death counters.
* Includes regression coverage for recent replay history, death persistence, timer transitions, overrides, and tracker exports.
* Distributes unsigned installers with SHA-256 verification and rollback-capable in-app updates.
