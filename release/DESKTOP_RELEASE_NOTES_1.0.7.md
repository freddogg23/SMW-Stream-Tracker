# SMW Stream Tracker Desktop v1.0.7

Version 1.0.7 introduces a centered, responsive main dashboard and rolls the
latest tracking, navigation, localization, and reliability improvements into a
single desktop release.

## Changes

- Redesigns the main dashboard around centered Live Session, Game Controls, and
  Timers sections while preserving the panoramic banner.
- Keeps the platform status, current hack, My Tracker status, exits, deaths,
  timers, and playback controls together in a responsive layout.
- Improves in-app navigation for Overview, My Tracker, downloads, the SMW
  Central Catalog, Settings, OBS text settings, diagnostics, setup and health
  checks, and platform game libraries.
- Improves RetroArch game handoff, timer and death tracking, exit counting,
  timer grace behavior, and optional LiveSplit handling.
- Adds an upload-date filter to random play while continuing to select only
  downloaded and patched ROMs that match the chosen filters.
- Expands translations and language-aware Read Me and feedback behavior across
  English, Australian, Spanish, French, German, and Brazilian Portuguese.
- Restores the packaged banner and interface artwork and includes a permanent
  Tcl/Tk runtime fallback so updated installations can start reliably.
- Refreshes the main dashboard and SMW Central Catalog screenshots.

## Downloads

- `SMWStreamTracker_Setup_1.0.7.exe` - complete installer and repair package.
- `SMWStreamTracker_Update_1.0.7.exe` - updater for a working installation.
- `SMWStreamTracker_Desktop_1.0.7_Source.zip` - source, tests, documentation,
  installer definitions, and required assets.
- `SHA256SUMS_1.0.7.txt` - SHA-256 checksums for every release download.

These files are intentionally unsigned, so Windows can display an Unknown
publisher or Microsoft Defender SmartScreen warning. Compare downloaded files
with the published SHA-256 checksums before running them.

SMW Stream Tracker never includes or downloads a commercial Super Mario World
base ROM. Users must provide their own legally obtained clean ROM when applying
moderated patches.
