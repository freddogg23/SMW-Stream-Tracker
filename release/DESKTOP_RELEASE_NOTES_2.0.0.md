# SMW Stream Tracker Desktop v2.0.0

Version 2.0.0 is the complete Stream Desk release. It brings the redesigned
interface to the full application and installer while expanding game modes,
RetroAchievements support, filtering, platform setup, and release reliability.

## Highlights

- Stream Desk styling now covers the dashboard, settings, libraries, game-mode
  windows, setup tools, dialogs, popups, help screens, and Windows installer.
- Adds Hot Potato and Mario Kaizo Challenge with curated playlists, automatic
  next-hack queues, persistent challenge exits, and dashboard mode controls.
- Adds guided RetroAchievements setup, compatible-core launch support, trophy
  markers, and RetroAchievements filtering throughout the catalog views.
- Adds consistent advanced filters for title, creator, difficulty, type,
  release state, Hall of Fame, waiting moderation, and RetroAchievements.
- Improves responsiveness when opening My Tracker, settings, catalog views,
  and Download & Patch Missing Hacks, while removing legacy-color flashes.
- Normalizes every RetroArch launch to prevent accidental fast-forward and
  removes the on-screen FPS counter from tracker-launched sessions.
- Improves installer and updater reliability, including faster QUsb2Snes
  extraction, consistent checkboxes, and the complete v2.0.0 release package.
- Updates every shipped translation for the redesigned interface and new
  release features.
