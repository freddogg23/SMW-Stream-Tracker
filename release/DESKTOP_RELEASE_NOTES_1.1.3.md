# SMW Stream Tracker Desktop v1.1.3

Version 1.1.3 adds consistent, persistent appearance controls to every table.

## Table appearance

- Progress by Difficulty now colors only the Difficulty cell.
- Rate now displays a value-based gradient data bar that fills according to the completion percentage.
- Right-click Rate to choose the data bar's starting and ending colors.
- Right-click any table to choose solid, vertical gradient, alternating-row, Overview, or default colors.
- Table choices remain saved between sessions and updates.

## Included v1.1.2 improvements

- Clickable SMW Central page and patch-download links in the complete catalog.
- Centered list headings and cell contents.
- Direct per-difficulty color editing.
- Horizontal scrolling for the expanded catalog.
