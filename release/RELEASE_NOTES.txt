Release 1.0.3

* Switches the app, complete installer, and updater to unsigned distribution by design.
* Keeps update checks and installation inside SMW Stream Tracker.
* Verifies every downloaded updater against the SHA-256 value in the official HTTPS update manifest.
* Verifies rollback executables with a SHA-256 value saved before replacement.
* Version 1.0.2 users must run the full 1.0.3 installer manually once; later unsigned releases can update from inside the app.
