# SMW Stream Tracker Desktop v1.0.0

This is the first public release of SMW Stream Tracker.

## Highlights

- Always-on tracking for FXPAK Pro and RetroArch.
- Searchable SMW Central moderated-hack catalog, missing-hack downloader, and complete catalog viewer.
- Personal tracker with editable progress, ratings, playtime, colors, gradients, statistics, exports, and automatic backups.
- Stream-friendly current-hack and timer output for LiveSplit, OBS Studio, and Streamlabs Desktop.
- Optional SNI, QUsb2Snes, RetroArch, and the SNI-compatible bsnes-mercury Performance core in the setup wizard.
- Multilingual installer and documentation, including Australian.
- First-run health checks, redacted diagnostics, rollback-capable updates, and recovery backups.

## Tables and statistics

- Progress by Difficulty colors only its Difficulty cells.
- Rate uses a value-based gradient data bar that fills according to the completion percentage.
- Difficulty colors and Rate gradient colors can be changed directly from their right-click menus.
- Every application table supports persistent solid, gradient, alternating-row, Overview, and default color styles.
- Catalog links open the matching SMW Central page or patch download.
- Lists include centered contents, search, sorting, and horizontal scrolling where needed.

## Windows downloads

- `SMWStreamTracker_Setup_1.0.0.exe` - complete unsigned installer.
- `SMWStreamTracker_Update_1.0.0.exe` - checksum-verified in-app updater.
- `SMWStreamTracker_Desktop_1.0.0_Source.zip` - complete release source.
- `SHA256SUMS_1.0.0.txt` - SHA-256 checksums for every release artifact.

The application never includes or downloads a commercial Super Mario World base ROM. Users must supply their own legally obtained clean ROM for patching.
