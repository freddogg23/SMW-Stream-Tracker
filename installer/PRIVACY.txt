SMW STREAM TRACKER PRIVACY
==========================

SMW Stream Tracker does not collect telemetry and does not upload ROM files.

The app uses the network only for features the user requests or enables:

* SMW Central catalog and moderated patch information.
* GitHub release checks and signed updater downloads.
* Optional Google Sheets synchronization through the URL the user supplies.
* Optional installer downloads for SNI, QUsb2Snes, RetroArch, and Libretro cores.
* Local communication with SNI, QUsb2Snes, FXPAK Pro, or RetroArch.

Tracker data, settings, timer state, mappings, recovery backups, and error logs
are stored locally. Error logs may contain technical file paths, but the Copy
Diagnostics feature redacts usernames, ROM names, and personal paths before
placing a report on the clipboard.

SMW Stream Tracker never includes, downloads, or uploads a commercial base ROM.
