OPTIONAL SOFTWARE AND ROM NOTICE

This installer can download and set up optional third-party software:

* SNI from the official alttpo/sni GitHub releases.
* QUsb2Snes from the official usb2snes GitHub releases.
* RetroArch from the official Libretro build server.

These programs are separate projects and are governed by their own licenses.
They are not bundled into SMW Stream Tracker; the setup wizard downloads only
the options selected by the user.

Project and license information:

* SNI: https://github.com/alttpo/sni
* QUsb2Snes: https://github.com/usb2snes/usb2snes
* RetroArch and Libretro cores: https://www.libretro.com/
* Pillow: https://python-pillow.org/
* openpyxl: https://openpyxl.readthedocs.io/
* websocket-client: https://github.com/websocket-client/websocket-client
* pystray: https://github.com/moses-palmer/pystray

The exact license text distributed with each project controls. SMW Stream
Tracker does not change or replace those licenses.

SMW Stream Tracker does not include or download a commercial base ROM. Its
Download Missing Hacks feature retrieves moderated patch files and applies
them only to a clean Super Mario World ROM supplied by the user.
